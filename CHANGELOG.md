# Changelog – Themba Givers NPO Website

This document records the main changes, improvements and updates made to the Themba Givers NPO website throughout the WEDE5020 Portfolio of Evidence.

## Part 3 – JavaScript, Accessibility and Website Refinement
**Date: 27 October 2026**

### Improvements based on Part 2 feedback

- Improved responsive typography to make headings and paragraph text easier to read on smaller screens.
- Refined the mobile navigation to improve usability on smaller devices.
- Improved responsive image sizing to prevent images from displaying incorrectly on smaller screens.
- Refined the responsive layout to improve the arrangement of content across different screen sizes.
- Expanded the README to provide clearer project information, folder structure, setup instructions and website functionality.
- Improved the project references by using a more consistent Harvard-style referencing format.

### Website functionality

- Connected the five HTML pages to the shared external CSS stylesheet.
- Updated asset paths to use forward slashes and the existing IMAGES directory.
- Refined the existing CSS while retaining the original coral, dark teal, cream and gold colour scheme.
- Expanded the JavaScript code and added comments to make the functionality easier to understand and maintain.
- Added a responsive navigation toggle for smaller screens.
- Added an interactive image lightbox with close, previous and next controls.
- Added keyboard controls for the image gallery, including Escape and arrow keys.
- Added live search functionality to help visitors find relevant service information.
- Added a message for situations where no matching search results are found.
- Added an OpenStreetMap embed to help visitors identify the Diepsloot area.
- Added client-side validation to the enquiry and contact forms.
- Added feedback messages to guide visitors when completing forms.
- Added email application handoff using mailto links after successful form validation.

### SEO and accessibility improvements

- Added unique page titles to the five HTML pages.
- Added meta descriptions and relevant meta keywords.
- Improved image alternative text to describe the images to visitors using assistive technologies.
- Improved form labels and validation feedback.
- Added accessibility attributes to navigation and interactive elements.
- Improved keyboard accessibility for interactive website features.

### Documentation

- Updated the README with the project overview, technologies, folder structure and instructions for opening the website.
- Added information about the website's interactive features and limitations.
- Included references for the technologies and resources used in the project.

**Important implementation note:** The website uses a mailto handoff. It does not automatically send or store form submissions because no server-side email system has been configured.

## Part 2 – CSS Styling and Responsive Design

The Part 2 website received a mark of **82/100 (Level 4)**.

### Work completed

- Created an external CSS stylesheet to maintain consistent styling across the website.
- Added general styling for the body, header, navigation, main content, hero section, cards, images, lists, buttons, forms, contact section and footer.
- Applied a consistent colour scheme using coral, dark teal, cream and gold.
- Added hover effects to navigation links, cards and buttons.
- Added focus styling to improve the visibility of interactive form controls.
- Added responsive media queries at 768px and 480px.
- Adjusted navigation, cards, footer spacing, typography and form layouts for smaller screens.

### Feedback received

The Part 2 assessment identified the following areas for improvement:

- Responsive layout: Minor layout issues were identified.
- Responsive typography: Text sizing required further improvement on smaller screens.
- Responsive navigation: The mobile navigation required improvement.
- Responsive images: Image sizing and responsiveness needed further attention.
- README: More detailed project documentation was recommended.
- References: The reference list needed more complete and consistent formatting.

These areas were used as a guide when refining the website in Part 3.
